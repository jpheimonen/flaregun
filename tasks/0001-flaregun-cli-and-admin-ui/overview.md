# Flaregun CLI and Admin UI

A Bun-native CLI tool that manages a single domain's entire Cloudflare stack — tunnels, DNS, access control, static sites with serverless functions, and local services — from a single YAML config file. Includes a built-in admin dashboard at `admin.yourdomain.com` for config editing, service management, and live log streaming.

Extracted and generalized from an existing `personal-homepage` project that proved the concept for one domain. Flaregun productizes this into a tool anyone can use.
